먼저 다음 주간 회의를 "말 없이 작업 카드를 벽(또는 공유 문서)에 붙이고 10분간 동시에 읽은 뒤, 겹칠 것 같은 카드만 얘기하고 바로 해산"하는 방식으로 딱 한 번 바꿔 보세요. 이유는 지금 90분 대부분이 10명이 차례로 말하는 시간일 텐데, 중복을 막는 데는 "읽기"만으로 충분하고 읽기는 10명이 동시에 할 수 있기 때문입니다.

(가정 3개: 회의는 한 명씩 돌아가며 진행 상황을 말하는 방식이다 / 팀이 티켓이나 공유 문서를 이미 쓴다 / 중복의 원인은 "서로 뭘 하는지 몰라서"다. 자세한 건 3번.)

## 1. 추천 3안 + 와일드카드

### 1. 말 없는 회의: 카드 붙이고 겹침만 이야기하기
- 뭘 하나: 회의 시작 전 각자 이번 주 할 일을 카드 1~3장(한 줄씩)으로 벽이나 공유 문서에 붙인다. 첫 10분은 말 없이 읽으며 "내 일과 겹칠 듯한 카드"에 스티커를 붙이고, 스티커 붙은 카드만 당사자끼리 이야기한 뒤 더 얘기할 게 없으면 즉시 해산한다.
- 왜 뻔하지 않나: 흔한 답 "발표를 30초로 줄이는 스탠드업"은 여전히 한 명씩 차례로 말하지만, 이 안은 말하기를 없애고 읽기를 동시에 하며 겹침 이야기만 남긴다.
- 가장 약한 고리: 카드가 두루뭉술하면(예: "개선 작업") 겹침이 안 보인다. 카드는 "무엇을 어디에 대해" 형식으로 써야 한다.
- 첫 실험: 10명 전원, 4주 동안 1·3주차는 새 방식, 2·4주차는 지금 방식 / 성공 = 새 방식 주의 회의가 평균 45분 이하(지금의 절반)이고, 금요일에 "동료 3명이 이번 주 뭐 하는지 적기" 정답률이 지금 방식 주보다 10%p 넘게 떨어지지 않음(주당 답 30개, 2주씩 합쳐 60개로 비교) / 비교 = 지금 방식 주 / 흐릴 요인: 마감·휴가가 낀 주.

### 2. 땅 나누기: 한 장짜리 영역 지도, 경계를 넘을 때만 알리기
- 뭘 하나: 첫 30분 동안 "사람 × 영역(고객·모듈·주제)" 표를 한 장 만들어 각 영역의 주인을 정한다. 이후 회의에서는 진행 상황을 말하지 않고, 자기 영역 밖의 일을 시작하는 사람이 한 줄로 알리는 것("경계 통보")만 다룬다.
- 왜 뻔하지 않나: 흔한 답 "칸반 보드로 상태 공개"는 모두의 진행을 다 보여주지만, 이 안은 다 알 필요를 없애고 겹침이 생기는 곳(경계)에서만 소통하게 한다.
- 가장 약한 고리: 일이 영역을 가로지르는 팀(대부분 협업 과제)이면 경계 통보가 매일 쏟아져 오히려 늘어난다.
- 첫 실험: 팀장 포함 3명이 종이 한 장으로 영역표를 만들고 3주 운영 / 성공 = 3주간 경계 통보 6건 이상(주 2건은 있어야 굴러가는 규칙이라는 뜻)이고 회의 평균 60분 이하(지금 90분에서 3분의 1 감소) / 비교 = 직전 3주의 회의 시간 / 흐릴 요인: 3주 사이의 프로젝트 국면 전환.

### 3. 알림 뜬 것만 만나기: 작업 흔적에서 겹침을 자동으로 찾기
- 뭘 하나: 사람이 보고하지 않고, 이미 쌓이는 흔적(티켓 제목, 문서 편집 기록, 커밋)에서 비슷한 작업 쌍을 골라 회의 전날 알려 준다. 회의는 이 쌍만 다루고 없으면 취소한다.
- 왜 뻔하지 않나: 흔한 답 "각자 진행 상황을 문서에 적기"는 사람이 쓰고 읽어야 하지만, 이 안은 아무도 쓰지 않고 기계(처음엔 사람 한 명)가 흔적을 훑어 겹침만 뽑아 준다.
- 가장 약한 고리: 티켓 제목이 모호하거나 일이 티켓 밖(구두 지시)에서 시작되면 흔적이 없어 못 잡는다.
- 첫 실험: 도구 없이 한 명이 월·수 10분씩 티켓·문서 제목을 훑어 비슷한 쌍을 메모, 4주 / 성공 = 뽑은 쌍 중 실제 겹침이 40% 이상(단, 쌍이 4주 합쳐 8개 이상일 때만 판정하고 미만이면 회의 시간만 본다)이고 쌍만 다룬 주의 회의가 40분 이하 / 비교 = 교대로 진행한 지금 방식 주 / 흐릴 요인: 훑는 사람의 눈썰미, 마감 주.

### 와일드카드. 일부러 겹치게 두고 금요일에 합치기
- 뭘 하나: 겹침을 막으려 회의하는 대신 "겹쳐도 된다"고 선언한다. 매주 금요일 30분을 "합치는 시간"으로 잡고, 같은 일을 한 사람들이 결과물 중 좋은 쪽을 고르거나 합친다.
- 왜 뻔하지 않나: 흔한 답은 모두 "겹침을 미리 막기"인데, 이 안은 겹침의 피해(낭비)를 줄여 미리 알 필요 자체를 줄인다.
- 가장 약한 고리: 중복으로 낭비되는 시간이 회의 비용보다 크면(고객 대응이 겹치는 등) 성립하지 않는다.
- 첫 실험: 코드 없이 종이 계산. 10명이 지난 6개월간 겪은 중복 사례를 각자 1건씩 적고 낭비 시간을 어림 / 성공 = 낭비 합계가 회의 비용(주 15인시 × 26주 = 390인시)의 4분의 1(약 100인시) 미만 / 비교 = 회의 비용 / 흐릴 요인: 기억 편향(큰 사건만 떠오름).

## 2. 다음 행동
1. 다음 회의에 1번 안을 그대로 한 번 실행(카드 형식은 "무엇을 어디에 대해" 한 줄). 다음 4주는 위 실험 표대로 교대 운영.
2. 회의 전에 20분만 들여 와일드카드의 종이 계산을 해 보면 "회의를 줄여도 손해 없는지"가 먼저 나온다.
3. 결과가 애매하면 깊게 모드(40개 원리 전부 스윕)로 다시 돌릴지 알려 주세요.

## 3. 근거: 문제 재정의와 모순
- 기능 문장: 10명이 서로 무엇을 하는지 겹치기 전에 알게 하고(목적), 그 과정이 모두에게 90분의 지루함을 만들지 않게 한다(불편). "왜?"를 두 번 올리면 "중복 없이 팀 시간을 쓰는 것"이 되어, 회의가 아니어도 되는 경로를 열어 두었다.
- 가정(원인 단정 금지): "중복은 서로 뭘 하는지 몰라서 생긴다"는 가정이다. 틀리면(실제 원인이 우선순위 불명확이나 담당 미정이면) 1·3안이 무너지고 2안만 부분 유효하다. 가장 싸게 확인하는 법: 최근 중복 사례 3건을 돌이켜 "미리 알았다면 막았나?"를 본다.
- 모순 쌍: 기술적 모순 — 공유의 완전함을 높이면 회의 시간·지루함이 늘고, 줄이면 중복이 는다. 물리적 모순 — 회의는 모든 사람의 일을 알려야 하고(중복 방지) 동시에 각자에게 무관한 일을 알리면 안 된다(지루함).
- IFR(이상적 최종결과, 장치·수고 없이 목적이 저절로 이뤄진 상태): "회의 없이도 겹치기 전에 서로 알아서 피한다."
- 추천안별 연결(분리 = 반대 요구를 시간·공간·조건·수준으로 나눠 푸는 방식):
  - 1안: 시간 분리 — 읽는 시간(전원, 동시)과 말하는 시간(겹친 사람만)을 나눔.
  - 2안: 공간 분리 — 영역별로 나눠 각자는 자기 영역과 경계만 알면 됨.
  - 3안: 조건 분리 — 겹침이 감지된 조건일 때만 만나고 아니면 안 만남(IFR의 "저절로" 부분을 기계가 대신).
  - 와일드카드: 모순을 풀지 않고 겹침의 피해를 줄이는 안이며, 그래서 추천이 아닌 와일드카드다.

## 5. 부록

### 금지 목록 (뻔한 답)
1. 회의를 60분으로 타임박스 / 2. 안건 사전 공유와 진행자 강화 / 3. 격주·월 1회로 빈도 낮추기 / 4. 노션·슬랙에 주간 진행 상황 문서 / 5. 매일 15분 스탠드업 / 6. 두 팀으로 나눠 소회의 / 7. 칸반·티켓 보드로 상태 공개 / 8. 발표 순서·진행자 로테이션

### 발산 로그 (빠르게 모드: 5개 방향 × 2개 원리 + 극단화 도구 2개 이상)
- [추출] 진행 상황 발표를 빼고 겹침 의심 안건만 남김 — 예외만 논의
- [추출] "이번 주 안 할 것"만 선언 — 배제 선언으로 경계 드러남
- [차원 변경] 순차 발표를 벽에 붙여 동시 읽기 — 직렬을 병렬로
- [차원 변경] 사람 × 영역 2축 지도, 같은 칸에 두 명이면 겹침 — 공간 배치
- [범용성] 점심·커피 시간을 근황 공유로 겸함 — 기존 비업무 접점 재사용
- [범용성] 티켓 제목이 그대로 회의 자료 — 별도 보고 없음 (변형: 상태 문서)
- [동질성] 작업 제목을 "동사+대상+고객"으로 통일해 기계 비교 — 형식 통일
- [동질성] SKIP(통일해도 회의 시간은 안 줄어듦)
- [사전 반대조치] 과거 중복 사고 사례를 회의에서 예방접종처럼 복기 — 사고 기반 학습
- [사전 반대조치] 착수 24시간 전 질문 공지 — 착수 전 확인 (변형: 채팅 공지)
- [서두르기] 1인 30초 타이머 — (금지 목록 변형)
- [서두르기] 중복 확인 단계만 착수 시점에 30초로 압축 — 시점 질문
- [전화위복] 일부러 겹치게 두고 금요일에 합침 — 중복을 비교 재료로
- [전화위복] 지루함 신호(손 들기)를 자유 이탈 트리거로 씀 — 자기 선택 이탈
- [반대로 하기] 듣는 사람이 "들은 동료 일"을 요약, 당사자가 정정 — 청중이 능동
- [반대로 하기] 사후 보고 대신 착수 전 선언 — 시점 앞당기기
- [색·투명도 변화] 영역별 카드 색, 같은 색 두 명이면 신호 — 색 신호
- [색·투명도 변화] 문서에 "지금 보는 중" 표시 자동 — 사용 흔적 가시화
- [다른 채널로 대체] SKIP(음성 메모는 비동기 상태 문서와 같은 원리)
- 극단화, 크기·시간·비용 0/무한(STC): 회의 시간 0초 → 흔적에서 기계가 겹침 감지(3안) / 팀 규모 무한 → 영역 소유 없이는 불가능해 경계 규칙 필요(2안)
- 극단화, 먼 분야 유추: 개미 페로몬(지나간 흔적이 뒤 개체를 피하게 함 → 3안), 항공 관제(구역 분할, 경계 통과 시 인계 → 2안), 관제사 1명이 충돌 후보만 이어 줌(중개자)
- 다리 놓기(황당한 3개 → 핵심 한 줄): 말 못 하는 회의 → 읽기는 병렬(1안) / 개미 회사 → 흔적이 곧 보고(3안) / 전원 중복 허용 → 낭비만 작으면 정보가 덜 필요(와일드카드)
