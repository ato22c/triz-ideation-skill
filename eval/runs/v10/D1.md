먼저 뚜껑 안쪽에 맺힌 물이 튀김 대신 가장자리 홈으로 흘러가게 하는 돔 뚜껑을 종이 목업으로 만들어 30분 시험해 보세요. 이유는 김을 빼지 않고 물만 튀김에서 떼어놓아 열을 잃지 않으면서 눅눅함을 줄일 수 있고, 모양만 바꾸는 것이라 재료비가 늘지 않기 때문입니다.

## 1. 추천 3안 + 와일드카드

### 1. 물길 돔 뚜껑
- 뭘 하나: 뚜껑 안쪽을 가운데가 높은 완만한 돔으로 만들고 가장자리에 얕은 홈을 둔다. 뚜껑은 닫힌 채라 열이 유지되고, 맺힌 물은 튀김 위로 떨어지지 않고 벽을 타고 홈에 모인다.
- 왜 뻔하지 않나: 흔한 답 "구멍 뚫기·흡수 패드"는 김을 밖으로 빼거나 물을 스며들게 한다. 이 안은 김은 그대로 두고 물이 맺히는 자리와 고이는 자리만 정한다(솥뚜껑 물받이, 창틀 결로받이와 같은 방식).
- 가장 약한 고리: 눅눅함의 주범이 뚜껑에서 떨어지는 물일 때만 통한다. 아랫면이 더 눅눅하면 효과가 작고, 이동 중 흔들려 홈의 물이 넘칠 수 있다.
- 첫 실험: 매장 직원 1명이 기존 뚜껑에 종이·테이프로 돔과 홈을 흉내 낸 뚜껑과 기존 뚜껑에 같은 튀김 10조각씩 5회(군당 50조각) 담고 30분 뒤 꺾어 본다 → 성공 = 눅눅(휘어지는) 조각 비율이 기존의 절반 이하(예: 40%→20% 이하, 50조각이면 이 정도 차이부터 우연과 구별됨) / 비교 = 기존 뚜껑 / 흐릴 요인 = 배치마다 다른 기름 온도.

### 2. 예열한 용기
- 뭘 하나: 포장 대기 중인 빈 용기와 뚜껑을 튀김기 옆 따뜻한 선반에 두었다가 튀김을 담는다. 차가운 용기 벽이 열을 빼앗고 김을 물로 바꾸는 처음 몇 분이 사라진다.
- 왜 뻔하지 않나: 흔한 답 "이중벽·보온 포장"은 담은 뒤 열이 새는 속도를 늦춘다. 이 안은 담기 전에 용기 자체가 열을 훔쳐 가는 것을 막는다. 재료 추가가 없다.
- 가장 약한 고리: 열에 약한 재질(발포 PS 등)은 못 쓴다. 효과가 처음 10분에 몰려 있어 배달이 오래 걸리면 차이가 작아진다.
- 첫 실험: 한 매장이 3일간 피크 시간 하루 5번씩 예열 용기와 상온 용기를 번갈아 쓴다(군당 15회) → 성공 = 20분 뒤 튀김 중심 온도가 5℃ 이상 높고(적외선 온도계, 오차 ±2℃보다 커야 판정 가능) 눅눅 조각 비율도 낮음 / 비교 = 상온 용기 / 흐릴 요인 = 시간대별 주방 온도·주문량.

### 3. 도착 시각 역산 조리
- 뭘 하나: 라이더 픽업 예상 시각이 나오면 마지막 튀김 시작을 그 시각에 맞춰 늦춘다. 포장이 끝난 뒤 뚜껑 닫힌 채 김만 차는 픽업 대기 시간을 없앤다.
- 왜 뻔하지 않나: 흔한 답은 용기가 열과 김을 더 잘 다루게 하는 것이다. 이 안은 용기가 버텨야 하는 시간 자체를 줄이고, 용기 단가는 그대로다.
- 가장 약한 고리: 픽업 시각 예측이 틀리면 라이더가 튀김을 기다려 불만이 생긴다. 조리 시간이 짧은(5분 안팎) 메뉴에만 맞다.
- 첫 실험: 협력 매장 1곳, 2주간 홀수일은 역산 조리·짝수일은 기존 방식으로, 종이 표에 "포장 완료→라이더 픽업" 분을 기록(군당 30건 이상) → 성공 = 평균 대기 5분→2분 이하이고 라이더가 3분 넘게 기다린 건이 10% 미만 / 비교 = 기존 방식 날 / 흐릴 요인 = 비 오는 날 배차 지연.

### 와일드카드. 국물 용기를 보온기로 쓰는 겹쳐 얹기
- 뭘 하나: 튀김 용기 바닥을 같은 주문의 뜨거운 국물 용기 뚜껑 위에 안정되게 얹는 홈을 만든다. 국물이 가진 열이 아래에서 튀김 용기를 데워 주니, 튀김 용기는 열을 가두려고 꽉 닫을 필요가 줄어든다.
- 왜 뻔하지 않나: 흔한 답 "보온백·발열팩"은 열을 따로 사거나 새지 않게 막는다. 이 안은 이미 같이 가는 뜨거운 국물의 열을 공짜로 빌린다.
- 가장 약한 고리: 국물 메뉴를 함께 주문한 경우에만 통한다. 국물 용기 뚜껑이 눌려 새면 사고가 된다.
- 첫 실험: 기존 국물 용기 위에 기존 튀김 용기를 테이프로 얹은 것과 튀김 용기 단독을 30분 방치하고 중심 온도를 잰다(5쌍 이상) → 성공 = 겹친 쪽이 8℃ 이상 높음(온도계 오차의 4배, 입에 미지근하게 느껴지는 경계를 벗어나는 최소 차이로 잡음) / 비교 = 단독 용기 / 흐릴 요인 = 국물 양과 처음 온도.

보조 아이디어(흔한 답의 변형이라 추천에서 내림): 뚜껑 안쪽 물 맺힘 방지 코팅, 습기가 차면 저절로 열리는 종이 덮개, 뜨거운 소스 컵으로 온기만 보충하고 튀김은 식혀 담기, 튀김을 세워 담는 콘형 칸.

## 2. 다음 행동

3. 나온 후보가 부족하면 방향을 더 넓혀 다시 돌릴 수 있다.

## 3. 근거

**가정(되물을 수 없어 임의로 잡음):** 배달은 20~40분, 종이 또는 PP 용기에 뚜껑이 있고 가게에서 튀겨 바로 포장한다. "단가 유지"는 개당 재료비 기준이며 금형 수정 1회 비용은 별도로 본다(확인 필요). 이미 해본 것은 알 수 없어 통풍구·흡수 패드 등을 흔한 답으로 잡았다. 이번엔 사용자가 모드를 정하지 않아 빠르게 모드(5개 방향, 원리 10개)로 돌렸다.

**핵심 원인은 가정이다:** "눅눅함은 뚜껑·벽이 튀김보다 차가워서 김이 물로 변해 튀김에 닿기 때문이다." 틀리면(예: 튀김 자체의 기름과 수분이 바닥에 고인 게 주범이면) 1번과 2번이 약해진다. 가장 싸게 확인하는 법은 2번 행동의 윗면/아랫면 세기다.

**기능 문장:** 튀김이 먹는 순간까지 바삭하고 따뜻하게 남게 하고 싶은데, 열을 가두면 김이 차서 눅눅해지고 김을 빼면 식어서 곤란하다. 더 넓은 목표("먹는 순간 바삭·따뜻")로 올려 봐도 용기 밖(조리 시각)까지 후보가 넓어질 뿐 같은 문장이라 유지했다.

**모순 쌍:** 기술적 모순 = 보온성을 높이면 바삭함이 나빠지고, 통기를 늘리면 온기가 나빠진다. 물리적 모순 = 용기는 열을 지키려고 닫혀 있어야 하고, 김을 내보내려고 열려 있어야 한다.
**이상적 최종결과(IFR, 비용·장치 없이 목적이 저절로 이뤄지는 상태):** 튀김의 열은 그대로 남고 김이 만든 물은 저절로 튀김에서 사라진다.
**자원:** 튀김기 옆 열, 포장 대기 시간, 같은 주문의 뜨거운 국물, 라이더 픽업 예상 시각, 뚜껑 안쪽 빈 공간.

**추천안별 연결(분리 방식이 서로 다르게):**
- 1번 물길 돔 뚜껑: 공간 분리. 열은 용기 전체에 가두고 물은 튀김과 다른 자리에 모아, 모순의 두 쪽을 모두 살린다.
- 2번 예열: 조건 분리. 용기 벽이 차가울 때만 김이 물로 변하니, 벽을 미리 데워 "닫아도 물이 안 생기는 조건"을 만든다.
- 3번 도착 시각 역산: 시간 분리. 닫혀 있어야 하는 시간을 줄여 모순이 작동하는 구간 자체를 줄인다. 눅눅함의 직접 원인은 못 푼다.
- 와일드카드: 수준 분리. 열은 용기 묶음 전체가 지키고, 습기 관리는 용기 하나하나에 맡긴다. 전제("열은 튀김 용기가 지켜야 한다")를 뒤집은 안이다.

- [9 windows: 상위 시스템×과거] 조리 종료를 픽업 시각에 맞춤 — 대기 구간 제거 (추천 3)
- [9 windows: 하위 요소×과거] 튀김옷을 수증기에 강한 구조로 — 금지 목록 ⑧과 동일
- [거꾸로 하기: 일부러 눅눅하게] 꽉 닫고 뚜껑 물이 튀김에 떨어지게 두기 → 뒤집어 떨어지지 않는 경로 — 추천 1과 같은 메커니즘

**용어 풀이:** 9 windows = 상위 시스템/지금/하위 요소 × 과거/현재/미래 3×3 표로 다른 칸의 자원을 찾는 도구. 이슬점 = 김이 물로 변하기 시작하는 온도.
