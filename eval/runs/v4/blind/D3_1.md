# 주간 회의 90분, 지루한데 없앨 순 없을 때

**전제(되물을 수 없어 가정):** 회의의 핵심 용도는 "서로 뭘 하는지 공유해 중복 작업을 막는 것"이다. 지식 노동 팀(개발·기획 등)이고 슬랙류 메신저가 있다. 회의 형식은 팀장이 바꿀 수 있다. 사전 공유 문서나 시간 단축 같은 흔한 처방은 아직 제대로 안 해봤다. 모드는 지정이 없어 "빠르게".

## 1. 추천 3안 + 와일드카드

**추천 1. 남의 일 맞히기 게임 (회의를 "발표"에서 "놀란 것만 논의"로)**
- 요약: 회의 5분 전, 각자 배정된 동료 2명이 이번 주 뭘 할지 한 줄로 예측해 적는다. 당사자가 실제와 대조하고, 예측이 빗나간 것(= 서로 몰랐던 것)만 회의에서 얘기한다.
- 왜 뻔하지 않은가: 흔한 답인 "사전 공유 문서를 미리 읽고 오기"는 읽었는지 확인할 방법이 없고 결국 다 발표하게 된다. 이건 예측이 맞은 것(이미 서로 아는 것)은 자동으로 건너뛰고, 모르던 부분만 남긴다. 무엇을 얘기할지를 예측 오차가 골라준다.
- 한계: 팀원 업무가 거의 안 겹쳐서 예측이 계속 다 틀리면 시간이 안 줄어든다. 남의 일을 대충 찍으면 효과가 없다.
- 첫 실험: 팀장이 다음 두 번의 회의에서 진행한다. 사람당 동료 2명 배정, 작성 5분. 회의 전 "지루했다"(1~5점) 평균을 재 둔다. 성공: 두 회의 모두 60분 이하이고 지루함 평균이 기준보다 1점 이상 내려감. 실패: 준비에 사람당 10분을 넘기거나 회의가 70분을 넘김.

**추천 2. 짝이 서로의 일을 소개하기 (듣는 사람이 발표자)**
- 요약: 회의 시작 전 2명씩 짝지어 5분간 서로의 이번 주 일을 3줄씩 물어보고, 회의에서는 자기 일이 아니라 짝의 일을 2분씩 소개한다.
- 왜 뻔하지 않은가: 흔한 답인 "담당자가 돌아가며 발표"는 자기 순서 외엔 남의 얘기를 흘려듣는다. 이건 남의 일을 소개해야 하니 짝 한 명의 일은 반드시 정확히 이해하게 되고, 소개가 틀리면 그 자리에서 바로 정정돼 이해가 검증된다. 9명의 얘기를 다 듣게 하는 대신, 팀 전체에 "아는 사람"이 두 배로 퍼진다.
- 한계: 짝이 매번 같으면 팀 전체 정보가 퍼지지 않는다(짝을 매주 바꿔야 한다). 소개 중 요점을 놓치는 사람이 있으면 왜곡된다.
- 첫 실험: 2주(2회) 진행. 시작 전 무작위 동료 3명의 이번 주 일을 맞히는 퀴즈로 팀 평균 정답률을 잰다. 성공: 회의 60분 이하이고 2주 뒤 정답률이 기준보다 20%p 이상 오르며 그동안 중복 작업 1건 이하. 실패: 회의가 75분을 넘기거나 정답률 상승이 10%p 미만.

**추천 3. "내 일 아님" 카드 (지루함을 신호로 쓰기)**
- 요약: 회의 중 자기와 무관한 이야기가 나오면 메신저 이모지로 "관련 없음"을 누른다. 3명 이상이 누르면 그 주제는 관련 당사자끼리 회의 직후 따로 처리하고 전체 회의에선 넘어간다.
- 왜 뻔하지 않은가: 흔한 답인 "필요한 사람만 참석"은 회의 전에 누가 필요한지 미리 정해야 하는데 그걸 아무도 정확히 모른다. 이건 참석자의 지루함이라는 기존에 버려지던 반응이 실시간으로 주제를 밖으로 밀어낸다. 다만 "주제별 자기 선택 퇴장"과 가까워 일부는 흔한 답의 변형이라, 나머지 두 안을 주력으로 쓴다.
- 한계: 눈치 보느라 카드를 안 쓰는 팀이면 작동하지 않는다. 카드 때문에 꼭 필요한 얘기가 밖으로 밀려 중복이 도리어 늘 수 있다.
- 첫 실험: 2회 진행. 성공: 회의 70분 이하이고, 밖으로 보낸 주제 중 이틀 안에 해결 안 된 것이 1건 이하. 실패: 회의당 카드 사용이 2회 미만(신호로 안 쓰임)이거나 미해결 주제가 3건 이상.

**와일드카드. 각자의 일 목록을 기계가 대신 겹쳐보기**
- 요약: 월요일 오전까지 각자 이번 주 할 일 3줄을 제출하면, AI가 10명분을 비교해 "겹칠 것 같은 쌍" 상위 5개만 뽑는다. 회의 첫 10분은 그 5개만 확인하고, 나머지 시간은 결정할 것에만 쓴다.
- 왜 뻔하지 않은가: 흔한 답인 "회의 AI 요약"은 회의에서 나온 말을 정리할 뿐이다. 이건 회의 전에 사람 대신 기록끼리 서로 비교해 겹침만 골라낸다. 모두가 남의 일을 읽어야 한다는 전제를 없앤다.
- 한계: 같은 일을 다른 말로 쓰면 못 잡는다. 업무 내용을 외부 AI에 넣는 게 보안상 막힐 수 있다.
- 첫 실험: 지난 4주 동안 실제 있었던 중복 작업 사례들의 당시 할 일 목록을 넣어 본다. 성공: 실제 중복 사례의 60% 이상을 상위 5개 안에 잡고, 그 5개 중 헛다리가 3개 이하. 실패: 잡는 비율 40% 미만.

## 2. 문제 재정의와 모순

- **기능 문장:** 팀원들이 서로의 진행 상황을 알아 같은 일을 두 번 하지 않게 한다.
- **왜? 2번 올리기:** 왜 서로 알아야 하나 → 중복이 낭비라서. 왜 낭비를 막나 → 팀의 시간을 새 일에 쓰려고. 더 넓은 목표: "팀이 같은 일을 두 번 하지 않고, 모두가 시간을 가치 있게 쓴다." 기능 문장은 이 범위로 유지하되 "사람이 다 듣는 것"은 필수가 아님을 확인했다.
- **기술적 모순:** 정보를 더 공유하면(개선 A: 중복 감소) 회의 시간이 늘고 지루해진다(악화 B: 집중도). 반대로 줄이면 중복이 는다.
- **물리적 모순(요소 하나가 서로 반대 성질을 요구받는 문장):** "각자의 진행 정보는 모든 사람에게 전달돼야 한다(중복 방지). 동시에 대부분의 사람에게는 전달되지 않아야 한다(자기와 무관하니 지루함)."
  - 분리 방법: 조건 분리(겹칠 때만 전달 → 추천 1·와일드카드), 수준 분리(전체는 개요만 알고 세부는 짝이 아는 것 → 추천 2).
- **IFR(이상적 최종결과, 비용·장치 없이 목적이 저절로 달성된 상태):** 겹치는 일이 생기려는 순간 관련된 두 사람만 저절로 알게 되고, 나머지는 아무것도 듣지 않는다.
- **자원 5개:** ① 사람: 이미 회의에 모이는 10명, 옆자리 동료 ② 시간: 회의 시작 전 5분, 점심·커피 대기 ③ 정보: 각자 이미 쓰는 티켓·커밋·메신저 기록 ④ 공간·물건: 매주 쓰는 90분 자체(비어 있는 시간이 절반 이상) ⑤ 기존 기능: 이모지 반응, 메신저 채널, 지루하다는 표정 자체.

## 3. 금지 목록 (뻔한 답)

1. 회의를 30~45분으로 줄이고 타이머 두기
2. 서서 하는 스탠드업으로 바꾸기
3. 사전 공유 문서/슬랙 스레드에 현황을 적고 회의는 질문만
4. 안건 정하고 진행자를 돌아가며 맡기
5. 칸반/노션 보드로 진행 상황 공유
6. 격주로 줄이거나 팀을 둘로 나눠 분반
7. 필요한 사람만 참석
8. 회의 녹음·AI 요약

## 4. 발산 로그 (빠르게: 5개 방향 × 2개)

- [4 비대칭] 발언 시간을 균등이 아니라 "중복 위험이 큰 쌍"에게만 몰아준다 — 위험도에 비례한 시간 배분
- [31 다공질] 점심·커피 대기 등 팀의 기존 빈틈에 "오늘 뭐 해요" 한 줄을 끼워 회의의 공유 부분을 대체 — 기존 빈틈에 공유를 채움
- SKIP(12 등위성): 정보를 같은 높이로 자동 노출하면 결국 공유 보드가 되어 금지 5번과 같다
- [24 매개체] 매주 돌아가며 "연결자" 1명을 지정, 회의 밖에서 팀원 일을 훑어 겹침을 개별 연결 — 중개자가 겹침만 전달
- [19 주기적 작용] 회의를 맥동으로: 10분 전체 → 25분 자유 퇴장 가능 소그룹 → 10분 전체 반복 — 전체와 부분의 교대
- [16 부분·과잉] 100% 공유는 포기하고 중복이 나면 하루 안에 잡아 보정, 잡은 사람에게 보상 — 예방 대신 조기 검출과 보정
- [26 복제] 동료의 이번 주 일을 예측(시뮬레이션)해 보고 실제와 대조 — 예측 오차로 논의 대상 선별 (추천 1의 씨앗)
- [22 전화위복] 지루함이라는 해로운 반응을 신호로 써서 주제를 밖으로 밀어냄 — 지루함이 필터가 됨 (추천 3의 씨앗)
- [22 전화위복, 두 번째 출발] 중복이 나면 낭비로 끝내지 말고 둘을 짝으로 붙여 서로 검증 — 중복을 교차검증 자원으로 전환
- [32 색·투명도] 여러 명이 같은 영역에 작업하면 화면에서 색이 진해지게 표시 — 겹침 가시화
- SKIP(28 다른 채널): 소리·촉각으로 현황을 전달하는 건 회의 문제와 안 맞아 억지

**극단화 도구 3개 사용**
- [시간 ∞·STC] 회의가 영원히 열려 있다: 상시 켜 둔 음성방에서 필요할 때만 들어옴 — 정보 교환 비용을 0에 가깝게
- [사람 수 0·STC] 아무도 참석하지 않고 각자의 대리인(AI)이 일 목록을 서로 비교해 충돌만 보고 — 사람 대신 기록끼리 매칭 (와일드카드의 씨앗)
- [시간 0·STC] 회의 0초: 새 일을 시작하는 순간 유사 작업 자동 경고 — 사후 공유가 아니라 시작 시점 검사
- [당연한 전제 뒤집기: "발표는 담당자가 한다"] 듣는 사람이 대신 소개한다 — 청자가 재진술해 이해가 검증됨 (추천 2의 씨앗)
- [먼 분야 유추: 개미의 흔적 신호] 개미는 회의 없이 흔적으로 서로의 작업을 피한다 → 새 작업 시작 시 30초짜리 "시작 카드"(제목+예상 결과물)를 남기고 시작 전에 검색 — 시작 행위 자체가 신호
- [먼 분야 유추: 항공관제] 공역을 구역으로 나눠 구역 소유자만 진입, 남의 구역에 들어가려면 먼저 교신 — 작업 영역 소유권 + 진입 시 통보
- [먼 분야 유추: 병원 교대 인수인계] 인수인계는 전체를 읽지 않고 "위험한 것 3줄"만 전달 — 위험 3줄만 남기기
- [거꾸로 하기] 회의를 더 지루하게 하려면: 전원이 모든 얘기를 끝까지 듣게, 결정 없이 공유만, 순서대로 전원 발표 → 뒤집으면 "공유는 글로, 회의엔 결정만"이지만 이는 금지 3번과 같아 새 후보 없음

## 5. 평가표 (다리 놓기 포함)

**다리 놓기 (황당한 3개에서 핵심만 살림):**
- 사람 0 대리인 → 핵심: "읽는 일을 사람이 아니라 매칭이 한다" → 현실판: 3줄 제출 + AI 겹침 후보 5개 (와일드카드)
- 상시 음성방 → 핵심: "교환 비용을 낮춰 필요할 때만 쓴다" → 현실판: 하루 한 시간 열린 시간대(보조 아이디어로 내림)
- 개미 흔적 → 핵심: "시작 행위가 곧 신호" → 현실판: 시작 카드 30초 (보조 아이디어로 내림)

**메커니즘 검사 (추천안, 가장 비슷한 무난한 답 / 작동 원리가 다른 점):**
- 추천 1: 사전 공유 문서 / 예측 오차가 논의 대상을 고른다 → 다름
- 추천 2: 돌아가며 발표 / 청자가 재진술해 이해를 검증하고 정보가 짝으로 퍼진다 → 다름
- 추천 3: 필요한 사람만 참석 / 참석자 반응이 실시간으로 주제를 걸러낸다 → 일부 변형 (시점만 실시간)
- 와일드카드: 회의 AI 요약 / 사람이 아니라 기록끼리 비교해 겹침만 뽑는다 → 다름
- 보조로 내림: 시작 카드(금지 5번 보드의 변형에 가까움), 맥동 회의(금지 1·7번 변형), 겹침 색(금지 5번 변형)

## 6. 다음 행동

1. 이번 주 회의 전에 "지루했다"(1~5점) 설문 1개와 동료 일 맞히기 퀴즈로 기준선을 재 둔다. 이게 없으면 위 실험의 성공·실패를 판단할 수 없다.
2. 다음 두 번의 회의에서 추천 1과 추천 2를 각각 한 번씩 시험한다(같은 주에 겹치지 않게).
3. 두 방식 모두 60분 이하로 못 줄이거나 중복 방지 효과가 없으면, 그때 와일드카드를 과거 사례로 재현 실험해 본다.
4. 결과가 빈약하면 "깊게" 모드(원리 40개 전체 스윕)로 다시 돌릴 수 있다. 원하면 알려 달라.
