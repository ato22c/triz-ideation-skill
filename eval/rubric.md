# 채점표 (100점)

채점자는 **문제 + 익명 답안 2개(1번/2번)** 만 본다. 어느 쪽이 스킬을 썼는지 모른다.
(답안 형식으로 짐작할 수는 있다 — 그래서 아래 기준은 형식이 아니라 **내용**을 채점한다.)

## 0. 사전 작업 — "무난한 답" 목록

답안을 읽기 **전에** 이 문제에 대해 AI가 가장 흔히 내놓을 답 8개를 스스로 적는다. 아래 B·C 채점의 기준이다.

## 항목

| 코드 | 항목 | 배점 | 채점 기준 |
|---|---|---|---|
| A | 문제 재정의·모순 | 20 | 해법 명사 없이 목적을 기능으로 다시 썼는가(6) / 개선↔악화 쌍 또는 "X는 P이면서 P가 아니어야 함" 형태의 진짜 모순을 짚었는가(8) / 모순을 푸는 방향(분리·IFR 등)이 이후 아이디어와 연결되는가(6) |
| B | 비전형성 | 25 | 답안이 **최종 추천한** 안들 중 "무난한 답 8개"와 메커니즘이 다른 안의 비율 × 15 + 그중 "생각 못 했는데 말 된다"고 느낀 안이 있으면 +10 (없으면 0, 1개 5, 2개 이상 10) |
| C | 다양성 | 15 | 답안 전체 아이디어를 메커니즘별로 묶었을 때 서로 다른 묶음 수: 3개 이하 3점 / 4~6개 7점 / 7~9개 11점 / 10개 이상 15점 (같은 메커니즘의 변형은 1묶음) |
| D | 구체성·검증 가능성 | 20 | 추천안마다 (작동 메커니즘 한 줄 / 적용 조건 또는 한계 / 가장 싼 첫 실험) 중 몇 개를 갖췄나. 추천안 전부 3개 다 갖추면 20, 비율에 따라 감점. 실험이 "설문해본다"처럼 막연하면 0.5로 계산 |
| E | 정직성 | 10 | 억지 끼워맞춤 없음(4) / 가정·불확실성 명시(3) / 자기평가가 부풀려지지 않음(3) |
| F | 전달력 | 10 | 결론이 맨 앞에 있고 비전문가가 바로 이해·결정할 수 있는가 (전문용어가 풀려 있는가 포함) |

## 채점 규칙

- 각 항목 점수와 한 줄 근거를 적는다.
- B는 **최종 추천안** 기준이다. 발산 로그에만 있는 아이디어는 C에서만 센다.
- 두 답안의 길이 차이는 D·F에서 이득이 아니다. 길다고 점수를 주지 않는다.
- 점수 인플레 금지: 100점은 없다. 평균적인 좋은 답은 60점대다.
- 1번/2번 중 어느 쪽이 더 나은지 한 줄 총평도 적는다.

## 출력 (JSON, `judge.json`)

```json
{
  "P": {
    "typical": ["…8개…"],
    "1": {"A": 0, "B": 0, "C": 0, "D": 0, "E": 0, "F": 0, "note": "…"},
    "2": {"A": 0, "B": 0, "C": 0, "D": 0, "E": 0, "F": 0, "note": "…"},
    "better": "1|2|tie"
  }
}
```
